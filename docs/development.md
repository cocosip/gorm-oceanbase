# gorm-oceanbase 开发文档（任务分解与进度）

本文档基于 [design.md](design.md) 定义开发任务，直接通过各任务的状态列表示当前进度。

**当前进度：已完成 21 / 32，进行中 6，未开始 5，受阻 0。下一项：G38 Oracle 错误翻译；M1 剩余 ◐ 项需真实数据库（G22）。**

**本轮说明**：M2 G37 Oracle Migrator 完成：表/列/约束/索引查询迁移到 Oracle 数据字典（all_tables、all_tab_columns、all_constraints、all_indexes + all_ind_columns、all_tab_comments、user_sequences），当前 schema 取 `SYS_CONTEXT('USERENV','CURRENT_SCHEMA')`，标识符按大写折叠加 owner 过滤；自增字段 FullDataTypeOf 在版本门槛通过时追加 `GENERATED BY DEFAULT AS IDENTITY`（非 ON NULL），CreateTable/AddColumn/AlterColumn 在未知或低于候选版本时于任何 DDL 前拒绝（ErrIdentityUnsupported）；DropTable 以字典查询替代 Oracle 缺失的 IF EXISTS 并使用 `CASCADE CONSTRAINTS`；ColumnTypes 以 `ISEQ$$` 默认值启发式上报自增、nullable/精度/刻度齐全；GetIndexes 联表标注主键/唯一并列出有序列集。`go build`、`go vet`、`go test ./...`、集成包无库编译与 golangci-lint 通过。AutoMigrate 全流程与主键 DDL 允许/拒绝的真实路径按 G39 验收。

**维护规则**：

- 开始任务时将该行状态改为 `◐`；满足该任务验收要求后改为 `✅`；受阻时改为 `⚠️`，在该行简述原因。部分完成保持 `◐`，在该行简述剩余工作。
- 每次更新任务状态，同步顶部进度汇总、下一项任务和阶段状态；阶段内所有任务验收通过后，阶段才标为 `✅`。
- 任务范围变化时直接修改对应行的内容、依赖和验收，并同步设计文档；不在文末追加工作日志或变更流水。
- 文档修订、临时审查实验和外部驱动测试不等于本仓库开发任务完成，不能据此标记 `✅`。
